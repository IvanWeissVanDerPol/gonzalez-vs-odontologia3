# 13 · Templates Procesales

Templates listos para que el abogado patrocinante los use o adapte. Cada uno está pensado para el caso específico de Gabi pero es parametrizable (los campos entre corchetes `[a completar]` son para reemplazar).

## Contenido

| Doc | Qué es | Cuándo usarlo |
|---|---|---|
| `35-poder-para-juicios.md` | Poder general para juicios | Antes de iniciar cualquier demanda |
| `36-escrito-conciliacion.md` | Reclamo ante el Viceministerio del Trabajo | Antes de demandar (obligatorio) |
| `37-oficios.md` | 8 oficios a IPS, SET, Registro Público, etc. | Durante la prueba anticipada |
| `38-cartas-documento.md` | 6 cartas documento (reclamo, citaciones, denuncias) | Cuando la contraparte no responde |
| `39-interrogatorios.md` | Preguntas estructuradas para confesional y testifical | Preparación de audiencias |

## Cómo usar

1. **Carlos imprime los que necesite** para audiencias o presentaciones.
2. **Adapta los campos entre corchetes** `[campo_a_rellenar]` con los datos del caso.
3. **Revisa antes de cada audiencia** que los templates correspondan al estado actual del caso.
4. **Mantén copia fechada** de cada escrito presentado.

## Numeración

Los templates usan numeración 35–39 para mantener trazabilidad con los docs de análisis (00–34) sin romper la numeración existente.
