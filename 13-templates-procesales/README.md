## Cómo usar

1. **Carlos imprime los que necesite** para audiencias o presentaciones.
2. **Adapta los campos entre corchetes** `[campo_a_rellenar]` con los datos del caso.
3. **Revisa antes de cada audiencia** que los templates correspondan al estado actual del caso.
4. **Mantén copia fechada** de cada escrito presentado.

## Numeración

Los templates usan numeración 35–39 para mantener trazabilidad con los docs de análisis (00–34) sin romper la numeración existente.
